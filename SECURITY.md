# Seguridad y credenciales

- No envíes credenciales AWS, contraseñas o documentos del centro a issues ni discussions públicas.
- Configura credenciales temporales de AWS Academy en `.env` local o en un perfil AWS CLI privado; ambos están excluidos de Git.
- Si aparece una credencial en un commit publicado, considera comprometida esa sesión: invalídala/renuévala en AWS Academy y elimina el secreto del historial público.
- Reporta vulnerabilidades al responsable del repositorio de forma privada mediante GitHub Security Advisories (si está habilitado) o un canal institucional acordado.
- Usa documentos de práctica autorizados. No almacenes expedientes ni datos personales de alumnos en el corpus.
